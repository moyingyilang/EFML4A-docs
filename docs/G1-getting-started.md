## 1. 先说这个项目在干什么

### 一句话

**想办法改掉《明日方舟：终末地》里的美术资源（图、模型），让游戏显示成你想要的样子。**

### 展开说

正常玩游戏的时候：

```
游戏 → 读资源文件（.chk） → 解压解密 → 显示在屏幕上
```

我们想做的事：

```
游戏 → 读【我们改过的】资源文件 → 解压解密 → 显示成我们想要的样子
```

**听起来很简单，但中间有一堆坎：**

```
坎 1: 资源文件是加密的，你得先能解密
坎 2: 解密完还是压缩的，你得能解压
坎 3: 解压完还有一层混淆结构，你得能读懂
坎 4: 找到你要改的那张图，改掉它
坎 5: 改完得重新加密压缩，而且大小要对
坎 6: 游戏可能会发现你改了，然后拒绝加载  ← 我们卡在这
```

**这个项目的文档，就是把这 6 个坎一个个讲清楚。**

## 3. 几个必须知道的概念

### 3.1 偏移（offset）

**「这个数据在文件的第几个字节处」**

```
文件: AAAAAAAABBBBBBBBCCCCCCCC
              ↑       ↑
           偏移 8   偏移 16
```

**看到 `off=4429838` 就是「从文件开头的第 4,429,838 个字节处」。**

### 3.2 长度（length / len）

**「这个数据占多少字节」**

```
off=4429838, len=9806
⇒ 从 4,429,838 开始，占 9,806 个字节
⇒ 范围是 [4429838, 4449644)
```

### 3.3 十六进制

**程序员常用 16 进制表示字节：**

```
0x00 = 0
0x0A = 10
0x10 = 16
0xFF = 255

一个字节 = 2 个十六进制字符
1A 3F 8B = 三个字节
```

### 3.4 大端 / 小端

**同一个数字，在文件里可以有两种存法：**

```
数字 0x12345678

小端（little-endian）: 78 56 34 12    ← 低位在前
大端（big-endian）:    12 34 56 78    ← 高位在前
```

**⚠️ 这个项目里两种都有！** 我踩过好几次坑。
读文档时看到「大端」/「小端」的标注要看清楚。

### 3.5 哈希 / md5

**「一串数据的指纹」。**

```
md5("hello") = 5d41402abc4b2a76b9719d911017c592
```

**性质：**
- 数据变了，md5 一定会变
- 从 md5 反推不出原数据
- 同样数据的 md5 永远一样

**在这个项目里的用途：** 游戏用 md5 检查文件有没有被改。

## 7. 常见疑问

### 「这是不是破解游戏？」

**不是。** 这个项目做的是：

```
· 读/改自己设备上的游戏文件（等长替换，随时能还原）
· 不修改游戏数值
· 不修改存档
· 不用于竞技作弊
· 不实现反作弊绕过
· 仓库里不包含任何游戏资源
```

**类比：** 这更像「读懂 ZIP 格式然后自己写个解压工具」，
而不是「破解软件授权」。

### 「为什么文档里直接写了密钥？」

**因为那是硬编码常量，不是机密。** 详见 [A6](A6-key-extraction.md) 第 8 节。

**简单说：**
- 它打在游戏二进制里，所有用户一样
- 已经在公开社区工具里存在多年
- 没有它谁也读不了自己设备上的文件
- 真正的保护在别处（完整性校验、反篡改）

### 「我能用这些工具做什么？」

**技术上：** 读、改、重建游戏的资源文件。

**实际建议：**
- 学习格式是完全可以的
- 但如果你要发布 mod，注意游戏的服务条款
- 不要用于多人游戏中的不当行为

### 「为什么不用 Python？」

**这个项目明确禁止 Python。** 见 [LANGUAGE.md](../LANGUAGE.md)。

**理由：**
- C 系工具可以直接编译成 Android 原生二进制
- 不需要运行时依赖
- 性能好（`fextract` 16 线程 3.5 秒提取 418 MB）
- 可复现（`make` 一键构建）

## 8. 遇到看不懂的怎么办

### 8.1 先跳过

**不要卡在一篇上。** 这个项目里有些内容（比如 A2 的三层混淆）
第一次读不懂很正常 —— 我写的时候也反复推翻了好几次。

**先读 A5（最实用）和 C2（最有意思），有感觉了再回来看 A2。**

### 8.2 用工具验证

**文档里说的每一件事，你都可以用工具自己验一遍：**

```bash
# 比如文档说「compBI = 101」
tools/.efml4a-bin/abverify bundle.ab
# 自己看输出是不是 101
```

**验证比阅读更能建立直觉。**

### 8.3 看归档

[`archive/`](archive/) 里有 76 篇旧文档，是完整的实验流水账。

**里面有很多「试了但不行」的记录。** 如果你卡在某个地方，
说不定我当年也卡过，翻翻可能有线索。

**⚠️ 但要注意：** 归档里有 7 个结论后来被我推翻了（见 [F1](F1-history.md)）。

## 10. 一句话总结

**这个项目证明了：在 Android 上改 Unity 游戏的资源，技术上是完全可行的。
唯一的障碍不是加密，不是权限，而是一个压缩后的大小对不上。**
