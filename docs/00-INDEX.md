# EFML4A · 研究文档

**《明日方舟：终末地》Android 端 mod 加载器 —— 逆向工程笔记**

---

## 这堆文档是写给谁的

如果你符合下面任何一条，这些文档就是为你写的：

- 你想知道《终末地》的 `.chk` / `.blc` / `.ab` 到底是什么格式
- 你想自己写一个工具去读或改这些文件
- 你也在做类似的事，想少踩几个坑
- 你只是好奇：一个手游的 mod 加载器要怎么做

**不需要你是逆向老手。** 每篇开头都会告诉你「这篇讲什么」「为什么重要」，
中间是推导过程，最后是能直接复制跑的命令。

---

## 先说结论（省得你翻半天）

**格式已经 100% 逆向出来了，工具也能正确读写，游戏甚至会接受你的修改 —— 但它会悄悄跳过你改过的那个文件。**

这不是加密的问题，也不是校验的问题。是**一个压缩后的大小变了 1 个字节**。

细节在 [C2 · 阻塞与失败记录](C2-blockers.md)。如果你想看一个真实的
「技术上都对，但就是不行」的案例，那篇值得读。

## 合规

这个项目只做研究：

```
· 等长替换，文件长度不变（随时能还原）
· 不改游戏数值、不改存档
· 不用于竞技作弊
· 不散布游戏资源（仓库里没有任何游戏资产）
· 不实现反作弊绕过
· 代码只用 C / C++ / C#，没有一个 Python 文件
```
